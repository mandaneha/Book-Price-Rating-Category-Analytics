# Book-Price-Rating-Category-Analytics

**CodeAlpha Data Analytics Internship – Projects and Tasks | Python, Excel & Tableau**

An end-to-end **data analytics project** completed during my CodeAlpha Data Analytics Internship, covering web scraping, data cleaning, exploratory data analysis, and interactive Tableau dashboard development using book data from Books to Scrape.

### 📈 Key Insights

* **Total Books:** 1,000
* **Categories:** 50
* **Average Price:** Approximately £12.48
* **Average Rating:** Approximately 3.87
* Analyzed book prices across different **star ratings and categories**.
* Compared **average price and average rating** across categories.
* Identified categories with different **price and rating patterns**.
* Examined the distribution of books across **price bands and star ratings**.
